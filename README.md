# CapitalG

CapitalG is a website for booking professional vehicle detailing services. Customers can explore available services, view examples of the work, and request an appointment online.

## Features

- Browse detailing services and starting prices
- View a gallery of completed work
- Submit an appointment request through the booking page

## Getting Started

Clone the repository and start a local web server from the project directory:

```bash
git clone https://github.com/KeepingItStoic/CapitalG.git
cd CapitalG
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser. The site is built with HTML, CSS, and JavaScript and does not require a package installation.
